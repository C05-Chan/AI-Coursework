How to run the genetic algorithms:

Required Software:
- Python

Python Libraries:
- Matplotlib
- Numpy
- Spider_plot (file within the zip folder)

To install required dependencies:
    Type `pip install matplotlib numpy`.

PLEASE CHECK!
- This line is at the top of the "genetic_algorithm" file: 
    `from spider_plot import plot_spider_pose`.

- "spider_plot.py" is in the same folder as your main script.

Once all that is done press "run" or if you are in a virtual environment type "python genetic_algorithm.py" OR "py genetic_algorithm.py" in the terminal.

Inputs: 
- You should not be asked to put any inputs!
- However, if you do want a better result on the GA , we do recommend changing the 'population' and the 'generations' to at least 300.
    - To do this, go into 'genetic_algorithm.py' and find the function called "main()" (it should be near the bottom).
    - There you should find "population = 150" and "generation = 250". These are the variables that needs to be changed for a better result.

Outputs:
- Generate new spider leg frames.
- Generate and saves all generated frames to a csv file called 'output_data.csv'.
- A display that shows a 3D animation of the spider frames.
- A window that shows the plotted average fitness across all generations and frames AFTER you close the spider animation window.

    Your terminal should look something like this:

    progress 1
    best [396.04999999999984]
    progress 2
    best [900.56]
    progress 3
    best [1013.7900000000001]
    ...
    progress 299 
    best [4305.9]
    Successfully wrote data to output_data.csv

How to run the neural networks:

Required Software:
- Python

Python Libraries:
- Numpy

To install required dependencies (if not done so already):
    Type `pip install numpy`.

Once all that is done press "run" or if you are in a virtual environment type "python neural_networks.py" OR "py neural_networks.py" in the terminal.

Inputs: 
- You are required to have a 'test_data.csv' in the same folder as 'neural_networks.py'!
    - Currently there should be a 'test_data.csv' already provided for you in the zip. However, if you would like the data from the 'genetic_algorithm.py' you can rename the 'output_data.csv' to 'test_data.csv'.

WARNING: the 'test_data.csv' must have more than 5 lines of example frames.

Outputs:
- The neural network learns to predict the 5th frame after given the last 4 frames.
- It should output 24 numbers that are similar to the target frame.
- The MSE should steadily decrease.
- Error vector should be close to zero.
- WARNING: Our prediction are not exact!
